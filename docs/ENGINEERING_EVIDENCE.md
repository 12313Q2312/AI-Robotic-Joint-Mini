# 工程证据与数据

## 本轮软件检查

`scripts/verify_joint_study.py` 运行现有59项 Python测试、C++参考行为组、配对夹具行为组、12个理想固定轴动力学工况及新旧面板前端回归。最终实际结果以 `data/verification/software_baseline_20261104.json` 和 GitHub CI 为准；测试数量属于不同统计口径，不合并为一个总数。

源码指纹与测试工具版本纳入摘要。验证范围为合成软件行为，不包含 ROS 2 插件构建、实际 Webots 反馈、SolidWorks 几何重读或硬件试验。

## 历史数据

| 文件组 | 内容 | 解释边界 |
|---|---|---|
| `experiment_0002`—`0007` | P、PD、恒定负载、PID和抗饱和 | 历史仿真控制实验，不与新场景混为同次验收 |
| `experiment_0008`—`0011` | ROS 2状态、可重复采集、传动与质量惯量示例 | 各文件配置和命令力矩语义独立 |
| `study_static_scan.csv` | 几何补偿参数/损耗敏感性离线扫描 | 合成静态计算，不是实测节能 |
| `assets/plots/` | 历史响应、抗饱和和PID分量曲线 | 与对应历史配置一起阅读 |
| T001 / 参考图 | 原生测试件与名义几何参考 | 不代表完整装配、材料/惯量、加工公差或CAD导入验收 |

部分历史场景元数据没有随本工程展示发布，因此保留这些 CSV 作为历史样例，不能据其单独证明实验已经完整复现。新增成果必须携带提交版本、配置、参数单位、原始结果和处理步骤。

本轮未新做仿真运动，不用旧实验数据证明当前配对夹具通过。公开文件完整性清单为 `data/verification/public_asset_manifest_20261104.json`；完整性哈希不证明工程结论正确。
